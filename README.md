# EaseUI

A modern, reusable React UI component library built with **React, TypeScript, Tailwind CSS, GSAP, and React Router**.

EaseUI provides reusable and customizable UI components along with interactive documentation/demo pages to make component usage easy to understand and integrate.

## ✨ Project Overview

EaseUI was initially provided as a partially completed UI library project. The task was to take the existing implementation forward, complete unfinished parts, and build the remaining components and demonstration pages into a functional and polished project.

During the development, I worked on completing and extending the existing codebase while independently implementing several components and pages from scratch.

## 🚀 What I Implemented

### Navbar

The existing Navbar implementation was incomplete, so I worked on completing and integrating the Navbar functionality into the project.

### Carousel

I implemented the **Carousel component and its complete demonstration page**.

The Carousel page includes interactive examples and demonstrates how the component can be used with different configurations.

### Form

The **Form component and Form demonstration page** were implemented from scratch.

The implementation focuses on reusable form structure and integration with the existing input components.

### Tooltip

I implemented the **Tooltip component and its demonstration page from scratch**, including positioning and interactive behavior.

### Layout

The **Layout component and Layout demonstration page** were implemented from scratch to provide a reusable structure for arranging content within the UI.

## 💡 Development Approach

The main goal of the project was not only to complete the missing functionality but also to maintain a reusable and scalable component architecture.

The implementation follows a component-based approach where UI elements are separated into reusable components and their corresponding demonstration pages.

Animations, themes, routing, and utility functions are also separated into their respective modules to keep the project organized.

## 📦 Getting Started

Clone the repository:

```bash
git clone https://github.com/ravsahebdev/EaseUI.git
```

Navigate into the project:

```bash
cd EaseUI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🏗️ Build

To create a production build:

```bash
npm run build
```
